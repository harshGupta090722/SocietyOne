















Forgot Password flow:

1)User clicks on forgot password-gets directed to forgot-password page
2)User enter his email and submits-which hits forgot password endpoint-backend
3)That end point generates a 32 char token,and creates a new entry in passwordResetModel Collection with an email,token and expiry,then sends the call sendResetPasswordEmail which sends an email to the user with the token using mailer.ts
4)Now the user receives an email with a link which contains the token and takes user to Reset Password page
5)User fills new paswords and confirms it,which sends request to reset-pasword endpoint-which updates the password in the DB
